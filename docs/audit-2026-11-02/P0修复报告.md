## 五、发布前必须处理的一项（不属于本次三项，但会阻断上线）

`release-manifest.json` 是审核过的发布锁文件。模拟 CI 打包后比对，**38 个文件与清单不一致**——其中 37 个在本次修复前就已不一致（工作区早于上次发版），本次新增的 1 个是 `base.css` 与 `style.css` 的合并计数。

CI 流程 `deploy-cloudbase.yml` 会执行 `check-release-manifest.cjs _site release-manifest.json`，**内容不一致即阻断部署**。因此上线前需：

```
node tools/build-release-manifest.cjs <发布目录> release-manifest.json
```
